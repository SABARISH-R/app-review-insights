# Real dataset: Spotify Google Play reviews, Jan–Jul 2022

Not committed. To get it:

```bash
git clone --depth 1 https://github.com/rizkyfernanda/P2--Spotify-Review-Analysis /tmp/sp
cp /tmp/sp/reviews.csv data/real/spotify_reviews_2022.csv
```

61,594 reviews of the Spotify Android app (1 Jan to 9 Jul 2022). Columns: Time_submitted, Review, Rating, Total_thumbsup, Reply. This is the public "Spotify App Reviews 2022" dataset from Kaggle.
